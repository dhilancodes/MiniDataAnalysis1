# Mini Data Analysis 1

This repository contains my Mini Data Analysis for STAT 545A, which explores the `womensmarchmadness` data set from the `diversedata` package. The analysis asks whether a team's regular-season wins relate to its tournament wins, and whether that differs by bid type.

## Files

- `MiniDataAnalysis1.qmd`: the Quarto file with all code and written answers
- `MiniDataAnalysis1.md`: the rendered version of the analysis, readable on GitHub
- `MiniDataAnalysis1.Rproj`: the RStudio project file
- `dat/`: folder of data files provided for the assignment

## How to use

Open `MiniDataAnalysis1.Rproj` in RStudio, install the packages listed at the top of the `.qmd` file (including `diversedata` from GitHub), then open `MiniDataAnalysis1.qmd` and click **Render** to reproduce the report.
